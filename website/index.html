What it does

Execution, not another chatbot.

CRANE is built for tasks that need planning, tools, durable state, and safe execution — not just a single model response.

01 / PLAN

Break down objectives

Turn a request into bounded workflow steps with explicit limits and observable progress.

02 / ACT

Use tools through MCP

Discover and invoke MCP tools through a policy-controlled boundary, with approvals for consequential actions.

03 / VERIFY

Track and recover

Persist task state, events, checkpoints and results locally so work can be inspected after submission.

Under the hood

Designed as a runtime.

A clear separation between process control, agent execution, model integration and external tools.

Get started

Install from PowerShell.

Windows 10/11 x64. The installer downloads the latest published CRANE release and installs the CLI for your user account.

PowerShell bootstrap
irm https://anubprad.github.io/crane/install.ps1 | iex

Review the installer source before running it. Releases are currently checksum-verified but not Authenticode-signed; do not treat this as publisher-signature verification. If no release has been published yet, the installer will stop without installing.

After installation:

agent doctor
agent run "Summarize what this folder contains"
agent status <task-id>
agent result <task-id>
